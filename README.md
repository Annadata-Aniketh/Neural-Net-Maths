# Maths mini-project

**UE25MA242A: Mathematical Foundation for AI & Data Science**

The refined project builds a neural network with explicit NumPy matrix operations and studies its hidden representations and singular values.

Start with [the project guide](neural_network_LA_project/README.md). The submission report is [PROJECT_REPORT.pdf](neural_network_LA_project/docs/PROJECT_REPORT.pdf), and the editable slides are [the PowerPoint deck](neural_network_LA_project/presentation/Neural_Network_Linear_Algebra.pptx).

```text
Maths/
├── README.md
├── references/                 Original problem sheet, source ZIP and extracted manual
└── neural_network_LA_project/
    ├── README.md
    ├── requirements.txt
    ├── src/                    Shared implementation and artifact builders
    ├── tests/                  Independent numerical checks
    ├── notebooks/              Guided notebook
    ├── docs/                   Report, speaker notes and viva guide
    ├── presentation/           PowerPoint, browser deck and shared slide content
    └── results/                Dataset, weights, metrics, histories and figures
```

Original reference contents are unchanged. The ZIP includes unrelated lab resources, retained inside the archive rather than unpacked through the project. The existing hidden Python environment remains available locally and is excluded from version control.
