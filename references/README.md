# Reference materials

- `mini_project_problem_statements.pdf`: original one-page problem sheet, renamed without changing contents. Its header gives UE25MA242A, which the user confirmed.
- `linear_algebra_lab_manual.zip`: original ZIP, renamed without changing contents. Contains a nested `LINEAR_ALGEBRA.zip` and the adapted Python lab manual.
- `applied_linear_algebra_manual.pdf`: exact copy of the adapted manual extracted from the ZIP, available for convenient reading.

The adapted manual credits **Anna Zemlyanova**, *Applied projects for an introductory linear algebra class*, under **Creative Commons Attribution-NonCommercial 4.0**. Preserve its attribution and license. The supplied adaptation mixes MATLAB and Python syntax in places, so the project verifies its NumPy computations independently.

The project draws on Project 10 (matrix transformations, PDF page 123), Project 11 (PCA, PDF page 139), and Project 14 (SVD and compression, PDF page 167). These are one-based PDF page numbers in the extracted adapted manual, different from its printed page numbering.

Unrelated images, the face database and other lab resources remain in the ZIP instead of being unpacked into the working project.
